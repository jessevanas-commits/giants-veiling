# Giants-veiling

Live veiling van 3 gedragen jerseys en de wedstrijdbal, tijdens de wedstrijd
Windrose Giants Antwerp vs Brussels op **zaterdag 14 november 2026**
(Wereld Diabetes Dag) in de Lotto Arena.

Bezoekers bieden alleen met hun naam. Er wordt niets betaald op de site.
De hoogste bieders worden tijdens de wedstrijd omgeroepen. De opbrengst
gaat naar [Hippo & Friends](https://www.hippoandfriends.com/nl)
(type 1 diabetes).

**Live site:** https://jessevanas-commits.github.io/giants-veiling/

De biedingen zijn pas live voor iedereen als de database is gekoppeld.
Zie [SETUP.md](SETUP.md).
