# Giants-veiling

Live veiling van 3 identieke gedragen jerseys en de wedstrijdbal.
De wedstrijd Windrose Giants Antwerp vs Brussels is op **zaterdag 14 november 2026**
(Wereld Diabetes Dag) in de Lotto Arena. De veiling sluit op
**vrijdag 20 november 2026 om 21:30** (Europe/Brussels).

Bezoekers registreren één keer hun naam, e-mail en telefoon (opgeslagen
op hun toestel) en bieden daarna alleen nog met een bedrag. Er wordt
niets betaald op de site. De winnaars worden na afloop per e-mail
gecontacteerd. Publiek is alleen de verkorte naam zichtbaar (voornaam +
eerste letter achternaam). De opbrengst gaat naar
[Hippo & Friends](https://www.hippoandfriends.com/nl) (type 1 diabetes).

**Live site:** https://jessevanas-commits.github.io/giants-veiling/

De biedingen zijn pas live voor iedereen als de database is gekoppeld.
Zie [SETUP.md](SETUP.md).
